that is not a character. Characters leave out the read-only password, typed once.

test-only id for its keychain entry, deleted after. Machine seconds exclude a person's
reading and thinking time.

## What each setup segment is

- **Commands typed** (4 / 66): `uv tool install probeowl`, `uv tool update-shell`,
  `owl --version` and `owl serve`. The guide still has `owl --version` as a check, as v0.1 did.
- **Setup: application** (7 / 24): Name (`Card baseline`) and Owning team (`access-team`),
  Next, untick Dev and Production, Preview, Create.
- **Setup: connection** (10 / 80): Add its first connection, MariaDB, then:
  - Host `127.0.0.1` (9 characters)
  - Database `access_uat_test` (15)
  - Read-only login `probeowl_test_ro` (16)
  - the password (not counted)
  - TLS: trust its certificate
  - the reason `the native test server's own certificate` (40)
  - Preview, Save

  Save tests the connection with the saved password, so there's no separate Test.
- **Import and confirm the labels** (2 / 0): Import its tables, Confirm all as suggested.
