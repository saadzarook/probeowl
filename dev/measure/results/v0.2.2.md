# v0.2.2: the newcomer path from first-run setup, on the new UI

Measured on 2026-11-21 with `bash dev/measure/newcomer_first_run.sh` (#27): three runs on the 0.2.2
release branch at b5814aa, ProbeOwl 0.2.2.
- **What changed since [0.2.1](v0.2.1.md):** every screen moved onto the UI foundation (#105): a
  new look, layouts for narrow screens, dark mode and a strict style policy. Setup, Add connection,
  the entity wizard and the probe editor were rebuilt on the same components, with the same fields
  and steps, so the counts are unchanged.
- **The install:** the wheel is built from that commit and installed cold, as `wheel_check.sh` does.
- **Where:** Windows 11, against the native MariaDB 11 (`access_uat_test`).
- **The example:** the same card example as the [v0.1.0 baseline](v0.1.0.md).

The counts were the same in all three runs. Machine time was 37.6 to 43.3 seconds; the table is
the first run.

An action is a command run, a click, a choice in a select, a field filled, or a key
that is not a character. Characters leave out the read-only password, typed once.
The connector id is left as suggested and not counted: the run replaces it with a
test-only id for its keychain entry, deleted after. Machine seconds exclude a person's
reading and thinking time.
