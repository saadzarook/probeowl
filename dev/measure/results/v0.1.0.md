# Baseline: the v0.1.0 wheel, before phase (a)

Measured on 2026-11-12 with `bash dev/measure/newcomer_baseline.sh 0.1.0` (#27): ProbeOwl 0.1.0
from PyPI, on Windows 11 against the native MariaDB 11 (`access_uat_test`). The card example: the
visitor and their cards, a Validate probe with `count(cards where status == 'active') <= 1`, run
on VP00012931, which fails as planted (two active cards).

The counts were the same in three runs; machine time was 32.2 to 35.8 seconds, nearly all of it
the cold install. A person's own time is the second measure, and an outside person's first run,
after phase (c), the third.

An action is a command run, an answer to `owl init` (Enter for a default counts),
a click, a choice in a select, a field filled, or a key that is not a character.
Characters leave out the read-only password, typed once. Machine seconds exclude
a person's reading and thinking time.
